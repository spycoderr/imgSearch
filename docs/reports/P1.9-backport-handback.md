# P1.9 memory backport hand-back

Search now loads the SigLIP text tower on CPU float32 with SentencePiece, and the
rewriter default is gemma3:4b with the upstream Hindi article prompt fix. The RAM
benchmark and query-vector comparison commands are included.

553 tests pass, ruff is clean, and upstream reports 6.89 -> 2.73 GB total search
memory. This figure was not remeasured locally. Run `ollama pull gemma3:4b` before
using the new default if that model is not already available.

Only RAM-related changes were imported; upstream faces, people search, near-duplicate
grouping and phone-batch features remain outside this backport.
