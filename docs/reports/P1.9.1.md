## Flags

- **`gemma3:4b` leaves some Hinglish queries untranslated.** "goa trip ki photos" comes back as typed (P1.9 eval:
  `u3-goa-trip` 0.60 with qwen's "photos of the Goa trip", 0.20 with gemma). It probably takes the query for
  English, given the prompt's "if the query is already in English, copy it exactly". Not tried here (the task was
  the Hindi miss). A sentence such as "a query with any Hindi word (ki, ke, wala, ...) is not English" could be
  tried under the same rule.
- **gemma keeps relation words** ("papa's birthday cake", P1.9 eval also "father by the river" for पापा), where
  the prompt asks for dad/mom; "mummy" did become "mom". The person boost uses `people`, which is unaffected.
- **gemma copies English request words** ("give me images of …"), which P1.9 already flagged (English −0.011
  vs qwen in P1.9; +0.003 on this copy).
- **The fix rests on one query.** Hindi has 8 queries; the gain is `dv-beach-boy` alone, and SigLIP ranks
  shift with articles both ways (`hi-iit-boy` scores 1.00 with "the boy standing …", 0 with qwen's "a boy
  standing …"). More labelled Hindi and Hinglish queries would make such checks firmer.
- `docs/reviews/P1.9.md` still says the rewriter stays `qwen2.5:7b`; it's the supervisor's file, not edited.
